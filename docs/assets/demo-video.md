Recording notes: Record 1920x1080 at 60fps, export 1080p. Terminal: JetBrains Mono 20pt (24pt for the closing card), dark theme, single-line prompt reading just a $ — rename the shell prompt so no username, hostname or absolute home path appears. Editor: same font at 18pt, sidebar/minimap/breadcrumbs/git gutter off, word wrap on. Browser: fullscreen, no tabs, no bookmarks bar, no extensions; page zoom 150% for card shots, 100% for the scroll. Cursor hidden on all pure-terminal shots (defaults write -g NSCursorHidden or just don't move the mouse and crop it out); for the two click shots set macOS cursor size to large and add a click highlight. Hide: Dock, menu bar clock, notifications (Do Not Disturb on), any .env or API key in scrollback, CLAUDE.md, and any real path under /Users — run the demo from a repo cloned to /tmp/launchjury. Run with --mock so the timings are fast and repeatable; if a real stage takes longer than its scene, speed-ramp the log scroll 4x rather than cutting mid-line. Record the hero shot (scene 1) last so the numbers on screen match the run in scenes 2-8. No music under the voice-over; a single soft keystroke bed is fine. Voice-over recorded separately, flat delivery, 135 wpm.
